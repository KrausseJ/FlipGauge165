# Sprint 1

## Goal

Establish a clean, minimal Connect IQ project that can be opened and built with Connect IQ SDK 9.2.0.

## Acceptance criteria

- `manifest.xml` targets `fr165`.
- `FlipGaugeApp` returns `FlipGaugeView` as the initial view.
- `FlipGaugeView` extends `WatchUi.WatchFace`.
- The simulator displays a black screen with centered white `FlipGauge` text.
