# FlipGauge165

Connect IQ watch face for the Garmin Forerunner 165.

## Current milestone

Minimal watch-face foundation:

- target device: Forerunner 165 (`fr165`)
- app type: watch face
- initial screen: black background with white `FlipGauge` text
- intended SDK: Connect IQ SDK 9.2.0

## Run in Visual Studio Code

1. Open the repository folder.
2. Open `source/FlipGaugeView.mc`.
3. Run the Monkey C project.
4. Select the Forerunner 165 simulator target.
