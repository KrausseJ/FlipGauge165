# FlipGauge165

Custom industrial flip-clock watch face for the Garmin Forerunner 165.

## Sprint 1 status

This first clean project version is intentionally minimal. It should:

- target the Garmin Forerunner 165 (`fr165`)
- compile as a Connect IQ watch face
- start in the Garmin simulator
- show a black background with the text `FlipGauge`

## Open in Visual Studio Code

1. Install the Garmin Monkey C extension and a current Connect IQ SDK.
2. Open this repository folder in Visual Studio Code.
3. Select the Forerunner 165 as the target device.
4. Run `Monkey C: Run App` from the command palette.

## Project structure

- `source/` Monkey C source files
- `resources/` strings, layouts and drawables
- `assets/` design source assets
- `docs/` project documentation
- `screenshots/` simulator and device screenshots
