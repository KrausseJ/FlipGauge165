# FlipGauge165

Open-source Garmin Connect IQ watch face for the Garmin Forerunner 165.

## Project status

Initial project structure. The watch face will be developed step by step and tested in the Garmin Connect IQ simulator before releases are created.

## Planned features

- Industrial retro flip-clock design
- Battery level
- Steps
- Heart rate
- Date
- AMOLED always-on mode
- Flip animation in a later development phase

## Target device

- Garmin Forerunner 165 (`fr165`)
