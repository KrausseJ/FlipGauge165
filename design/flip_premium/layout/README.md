# FlipGauge165 – Master Layout Blueprint

This package defines the approved 390×390 layout for Garmin Forerunner 165.

## Files

- `FlipGauge165_MasterLayout_390x390.png` – clean visual master
- `FlipGauge165_Blueprint_390x390.png` – grid and coordinate overlay
- `FlipGauge165_MasterLayout_390x390.svg` – editable vector reference
- `layout_coordinates.json` – exact element positions and dimensions

## Rule for the next implementation phase

The renderer and all assets must conform to these coordinates. No element should be repositioned ad hoc in Monkey C.
